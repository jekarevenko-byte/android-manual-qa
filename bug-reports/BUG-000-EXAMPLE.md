# BUG-000 (ПРИМЕР ОФОРМЛЕНИЯ, не реальный дефект): Введённый текст пропадает после поворота экрана

| Поле | Значение |
|---|---|
| Статус | New |
| Severity | Major |
| Priority | Medium |
| Приложение и версия | `<приложение>` 1.0 |
| Устройство / Android | Pixel 7 (эмулятор), Android 14 |
| Воспроизводимость | Всегда (5 из 5) |
| Связанный кейс | TC-003 |

## Предусловия
Открыт экран создания записи, поле пустое.

## Шаги воспроизведения
1. Ввести в поле «Название» текст «Тест».
2. Повернуть устройство в горизонтальную ориентацию.

## Фактический результат
Поле «Название» очищено.

## Ожидаемый результат
Введённый текст сохранён после поворота.

## Вложения
`evidence/BUG-000_rotation.mp4`

## Примечания
Тип дефекта типичный для Android: состояние экрана не сохраняется при пересоздании Activity. Обходной путь: не поворачивать экран при вводе.
